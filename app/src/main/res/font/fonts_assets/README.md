<p dir="auto">A project to create a coding font inspired by early 20th-century

<p dir="auto">And to practice editing fonts directly in FontForge.</p>
<div class="markdown-heading" dir="auto"><h2 tabindex="-1" class="heading-element" dir="auto">About This Font</h2><a id="user-content-about-this-font" class="anchor" aria-label="Permalink: About This Font" href="#about-this-font"><svg data-component="Octicon" class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This font is not the result of any scans or traces of samples,
specimens, or other output from an actual typewriter.  I personally
eyeballed and drew everything in FontForge.</p>
<p dir="auto">DSE Typewriter is more like an amalgamation of old-school typewriter
fonts with features semi-arbitrarily picked from each one, as well as
a few coding-friendly features that were not in use on actual
typewriters of the period.</p>
<p dir="auto">Though this is intended to be useful as a coding font, I emphasized on
aesthetics while maintaining some degree of readability.  There is
room for improvement.  I may create a version of this that borrows
from old "reproducing typewriter" fonts (e.g., Monotype No. 72L,
Reproducing Typewriter).</p>
<div class="markdown-heading" dir="auto"><h2 tabindex="-1" class="heading-element" dir="auto">Features and Characteristics</h2><a id="user-content-features-and-characteristics" class="anchor" aria-label="Permalink: Features and Characteristics" href="#features-and-characteristics"><svg data-component="Octicon" class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Relatively low ex-height.</p>
</li>
<li>
<p dir="auto">Lining numerals, i.e., all start at the baseline and end at the
same height.</p>
</li>
<li>
<p dir="auto">Full ASCII and Latin-1 coverage, along with selected extended
Latin, punctuation, graphic, and currency symbols.</p>
<p dir="auto">Includes every character you can type in the US International
Layout in Windows.</p>
<p dir="auto">Includes every character you can type on a Mac when the input
source is U.S.</p>
<p dir="auto">Includes all box drawing characters.</p>
<p dir="auto">Supports most western European languages.</p>
<p dir="auto">Includes basic Cyrillic.</p>
</li>
<li>
<p dir="auto">Coding-friendly distinctive characters: <code>li1|</code> <code>Oo0</code> <code>`'"</code></p>
</li>
<li>
<p dir="auto">Elite scale typeface (12 characters per inch at 12-point font
size).</p>
</li>
<li>
<p dir="auto">Perfectly useful as a traditional typewriter face for other
purposes, if you don’t mind the zero (0) having a dot in the
middle.</p>
</li>
</ul>
